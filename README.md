# 🚀 NASA Space Explorer

A visually stunning web application that lets you explore NASA's Astronomy Picture of the Day (APOD) and learn more about the universe. Built with a modern, space-themed design for an immersive experience.

## 🌌 Features

- **Daily Space Images:** Browse NASA's APOD with detailed explanations.
- **Interactive Navigation:** Easily view previous and next days' images.
- **Responsive Design:** Looks great on desktop and mobile devices.
- **Animated Background:** Dynamic, animated cosmic circles for a space vibe.
- **Error Handling:** Friendly messages if NASA's API is unavailable.

- **HTML5**
- **CSS3** (custom animations and effects)

- **NASA APOD API**

## 🚦 Getting Started Locally

1. **Clone the repository:**
   ```sh
   git clone https://github.com/manny2706/NASA--SPACE-EXPLORATION.git
   ```
2. **Open the folder in VS Code or your favorite editor.**
3. **Open `index.html` in your browser.**

No build steps or dependencies required!
